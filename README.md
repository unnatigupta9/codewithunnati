# 📚 My Study Tracker

This is a small Python project I made while learning Python.

It asks for the subject I studied and how many hours I studied. Then it gives me a simple message based on the time.

## Example

What subject did you study? Maths

How many hours did you study? 2

Today you studied Maths for 2.0 hours.
